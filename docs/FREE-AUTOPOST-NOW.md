# NahaLabs Free AutoPost — Now

- Local AutoSocial Studio under C:\Users\nahat\AutoSocial.
- Free/open-source publishing engine.
- No paid scheduler.
- No Meta or LinkedIn developer application.
- Instagram, TikTok and YouTube are the supported no-API browser path in the current AutoSocial release.
- A harmless five-second proof video is seeded into each queue.
- The local scheduler is set to a one-minute proof cadence.

## The only unavoidable action

The account owner must complete the first login inside AutoSocial. This creates the local browser session. After that, the queue can publish unattended on the local machine.

## Scope

This path does not add LinkedIn or Facebook browser automation. Do not automate platforms in ways that violate their rules. Use native scheduling or an official API for those networks later.

## Run

Double-click START-FREE-AUTOPOST.cmd from the local autopost-naha repository.
